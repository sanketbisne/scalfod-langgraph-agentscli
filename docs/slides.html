DeepCite Reference Workload 07 / 10

Iterative Research & Self-Critique Loop

Grounded retrieval and mandatory citation verification before generating the final technical report:

01 • Plan
create_research_plan

Decomposes complex prompts into structured sub-questions and targeted search queries.

02 • Search
search_curated_kb / arxiv

Retrieves evidence with explicit IDs ([KB-...], [ARXIV-...], [WIKI-...]).

03 • Critique
critique_research_draft

Audits draft claims for ≥ 2 distinct citations and depth; triggers revision if incomplete.

04 • Report
research-report CLI

Outputs Markdown with inline [SOURCE_ID] citations and a verified ## References section.

Live Demo • Act 4 09 / 10

Policy-as-Code: Custom sbom-deploy Gate

agents-cli-extension.yaml
schema: agents-cli-extension/v1alpha1
name: sbom-deploy
description: Scan project SBOM, then run native deploy.
requires:
  agents_cli: ">=1.5,<2"
  on_incompatible: warn

commands:
  override:
    deploy:
      run: ["bash", "scripts/sbom_then_deploy.sh"]
  add:
    sbom-report:
      run: ["bash", "scripts/sbom_report.sh"]
scripts/sbom_then_deploy.sh
#!/usr/bin/env bash
set -euo pipefail

echo "[sbom-deploy] Generating CycloneDX SBOM..."
syft dir:. -o cyclonedx-json > /tmp/sbom.cdx.json

echo "[sbom-deploy] Scanning for critical CVEs..."
grype sbom:/tmp/sbom.cdx.json --fail-on critical

# Loader sets AGENTS_CLI_DISABLE_OVERRIDES=1
# Delegates to built-in deploy with zero recursion!
exec agents-cli deploy "$@"
$ agents-cli extension add local@./extensions/sbom-deploy --yes AGENTS_CLI_DISABLE_OVERRIDES=1
